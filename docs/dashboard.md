# Dashboard & Visualization

## Overview

The Dashboard & Visualization layer provides a business-facing interface for the Intelligent Demand Forecasting Platform. It transforms machine learning predictions and agent decisions into actionable insights for business users, supply chain managers, and executives.

The dashboard integrates forecasting, trend analysis, anomaly detection, inventory optimization, and agent-based reasoning into a single interactive application.

---

## Objectives

The dashboard is designed to:

* Visualize demand forecasts
* Display trend and anomaly analysis
* Present inventory recommendations
* Explain agent decisions
* Provide executive-level business insights
* Improve transparency and interpretability of forecasting decisions

---

## Architecture

Forecasting Dashboard Workflow:

```text
User Input
    ↓
Streamlit Dashboard
    ↓
FastAPI Agentic Service
    ↓
Forecast Agent
    ↓
Trend Analysis Agent
    ↓
Anomaly Detection Agent
    ↓
Inventory Optimization Agent
    ↓
LLM Reasoning Agent
    ↓
Business Decision Output
```

## Dashboard Components

### Forecast Analysis

Displays:

* Predicted demand
* Forecast date
* Store information
* Product information

### Trend Analysis

Displays:

* Trend classification
* Trend explanation
* Business interpretation

### Anomaly Detection

Displays:

* Anomaly status
* Anomaly severity
* Operational impact

### Inventory Optimization

Displays:

* Current stock level
* Lead time
* Safety stock
* Reorder point
* Recommended order quantity
* Stockout risk
* Overstock risk

### Agent Reasoning

Displays:

* Agent workflow
* Decision reasoning
* Risk assessment
* Recommended actions

### Executive Summary

Provides a concise business-oriented explanation of the final recommendation generated by the multi-agent decision system.

## Running the Agentic API

Start the API service:

```bash
PYTHONPATH=. uvicorn src.api.agentic_main_llm:app --host 0.0.0.0 --port 8002
```

API documentation:

```text
http://127.0.0.1:8002/docs
```

---

## Running the Dashboard

Start Streamlit:

```bash
streamlit run src/dashboard/app.py
```

Dashboard URL:

```text
http://localhost:8501
```
